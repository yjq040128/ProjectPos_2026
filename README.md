# ProjectPos_2026 (Supermarket POS System)

A lightweight, standalone Point-of-Sale (POS) system for a small supermarket, built in Python. This project was developed following Agile (Scrum) practices over 3 Sprints.

## Features
- **Process Sale:** Create new sales, enter items, calculate totals, accept cash, and print receipts.
- **Handle Returns:** Look up historical sales, record returned items, calculate refunds, and update inventory.
- **Layered Architecture:** Clear separation of UI Layer, Domain Layer, and Technical Services.

## Agile Process
- **Sprint 1:** Core sales entry workflow.
- **Sprint 2:** Cash payment, change calculation, and receipt generation.
- **Sprint 3:** Return workflow, refund calculation, and final design integration.

## Project Structure
- `main.py`: The core Python application containing all business logic.
- `Report.pdf`: The complete software engineering practice report (Part 1: Agile Process, Part 2: OOA/D).
- `README.md`: Project overview.
